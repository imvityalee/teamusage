How it works

1

Create a team

Sign in with GitHub, name your team and get its team code on the site.

2

Send the code to your team

Each person installs the plugin for Claude Code or Codex and enters the team code, their name and their email.

/plugin install teamusage@teamusage
3

See the numbers

Usage is sent when a session starts and when it ends. The dashboard shows it by person, agent, model and day.

What is sent, and what is not

One small record per day, agent and model. You can print the exact payload before anything is sent.

Sent

  • Date, agent and model
  • Token counts: input, output and cache
  • Estimated cost in US dollars
  • Your name and email, once, when the machine joins
  • The machine's hostname, as a label
  • Account kind, organisation name and plan, for Claude and Codex

Never sent

  • Prompts or replies
  • Code, file paths, project or repository names
  • Session contents
  • Account emails, account IDs or sign-in tokens

Check it yourself: teamusage sync --dry-run prints the payload and sends nothing.

Where the data lives

On this site your team's numbers are stored on our server in Frankfurt. The team's owner chooses who can open the dashboard: every member, or only its admins. The owner can delete the team and all its data at any time. To hold the data yourself, run the open-source server in one container.
